# Name shortlist

Checked 2026-10-10 against crates.io, PyPI, Repology (which covers Debian, Ubuntu, Fedora, Arch/AUR, Homebrew, Nix
and others), Homebrew, and a web search. GitHub's own pages were blocked from this box, so `FieldmouseWorks/<name>`
availability gets confirmed when the repo is created.

| name | why | collisions |
|---|---|---|
| **wend** (pick) | "to wend your way": slow, deliberate travel from A to B, which is exactly what a route is. Four letters, one syllable, reads as a verb: `wend etch trixie`. | crates.io: **free**. PyPI: taken. Repology: one obscure AUR Wayland slideshow tool. No well-known Linux command. |
| stile | The step built into a fence so you can cross from one field to the next. That's one hop. Fieldmouse-adjacent. | crates.io: a 20-download squat. Not in any distro. |
| hedgerow | Where field mice actually live, and a row of hops joined into a path. Charming but long to type. | Free on crates.io and PyPI. Not in any distro. |
| waymark | A trail marker that someone who walked the route before you left behind. That's a verified fix. | crates.io: a navmesh pathfinding crate (730 downloads). |
| cairn | Stacked stones marking a trail, added to by everyone who passes. The best metaphor on the list. | Crowded: an AI coding-agent project, a coding-agent repo map, a blockchain, a GNOME task app (AUR), a crates.io crate. |
| outgrow | What an old server does to its release. Self-explanatory. | Free on crates.io. Slightly sad as a verb. |
| furrow | Field theme, a groove you follow. | crates.io: an ssh git remote tool (1.2k downloads). |

**Pick: wend.** It's short, it's a verb, it's free where it matters for a Rust binary (crates.io), and nothing on a
Linux box answers to it. The metaphor holds up: you don't jump releases, you wend through them. Under the org it
reads as `FieldmouseWorks/wend`, and the docs call the repo of fixes "the wend map".

Runner-up: stile, if you want the fieldmouse theme louder.
